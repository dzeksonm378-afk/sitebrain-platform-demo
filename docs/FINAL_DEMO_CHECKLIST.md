# Final Demo Checklist

Use this checklist before generating the final QR code and showing SiteBrain from the stage.

- [x] `npm run lint` passed locally.
- [x] `npm run build` passed locally.
- [x] All routes open locally.
- [x] Dashboard visible.
- [x] Simulate AI Event works.
- [x] Mobile view checked.
- [x] No horizontal overflow found in local checks.
- [x] No console errors found in local checks.
- [ ] Vercel deployment URL ready.
- [ ] QR code tested on phone.
- [ ] Presentation slide contains final URL QR.
